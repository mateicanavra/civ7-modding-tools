# Flow Set

Use these chains to trace actor intent through owner-local facts. Every arrow
preserves authority; every proof supports only its named claim.

## Official Facts

```text
identified Civ7 installation/resources
  -> qualified extraction and publication receipts
  -> published official-resource revision
  -> deterministic generated types/policy
  -> public pure consumers
```

Honest close: source identity, revision, digest, and generated-currentness.

Forbidden claim: generated contracts prove current live-engine behavior.

## Generic Mod Definition And Production Realization

```text
mod-author intent
  -> SDK plus portable mod definition
  -> admitted definition and deterministic render plan
  -> matching realization app's finite build/deploy entrypoint
  -> qualified materialization and installation receipts
  -> independent loader and live-behavior evidence
```

Honest close: each definition, artifact, installation, loader, and live fact is
reported independently.

Forbidden claim: definition or generated output proves installation or loader
acceptance.

## Swooper Definition And Generation

```text
map-author intent
  -> Swooper portable definition
  -> MapGen product-neutral language/mechanics
  -> admitted config and deterministic execution
  -> artifacts, trace, metrics, diagnostics, and visualization
  -> owner Questions about the exact inputs and result
```

Honest close: deterministic Swooper truth for the admitted config, seeds,
setup, and map size.

Forbidden claim: browser projection or deterministic artifacts are
engine-current Civ7 truth.

## Map Configuration Authoring

```text
author intent
  -> Studio web/API projection
  -> Swooper definition admission/serialization
  -> app-bound prepared source write
  -> exact write or rollback receipt
  -> caller projection of owner facts
```

Honest close: canonical config identity plus exact source-write or rollback
evidence.

Forbidden claim: saved means deployed, loaded, or run.

## Studio Ephemeral Map Realization

```text
run-operator intent
  -> Studio web/API projection
  -> MapGen-runs public client
  -> operation admission, identity, order, and state
  -> app-bound config/run/log/realization/clock capabilities
  -> Studio Swooper realization adapter
       -> ephemeral materialization/install effects and receipts
  -> public controller-client setup/readback facts
  -> MapGen-runs correlation, reconciliation, and final semantic outcome
  -> Studio projection
```

The Studio adapter is constructed from the public Swooper definition plus pure
workspace/install packages. It does not import the production realization app
or invoke its targets. MapGen-runs owns semantic operation meaning; adapters
own exact effects and receipts.

Forbidden claim: API return, physical deployment receipt, or controller readback
alone is the MapGen-runs outcome.

## Civ7 Controller

```text
live-operator or dependent-capability intent
  -> CLI/API projection or public service dependency
  -> host app selects Tuner and verifies controller realm/boot identity
  -> host app binds the public controller client to the versioned ingress
  -> typed envelope carrying no operation implementation body
  -> closed native operation executed by controller TypeScript inside Civ7
  -> correlated native fact, dispatch, readback, refusal, or uncertainty
  -> requesting owner
```

Honest close: exact host-access evidence plus the controller-issued realm/boot
and native operation result.

Forbidden claim: raw transport success or native dispatch is gameplay value or
acceptance.

## Actor-Facing Play

```text
player or agent intent
  -> game-play CLI or selected caller projection
  -> play public client
  -> situation, check, request, reconciliation, and no-repeat policy
  -> public controller client
  -> exact native controller fact or transition
  -> play-owned outcome and next lawful action
  -> caller projection
```

Honest close: no-op, refusal, confirmed effect, or explicit reconciliation with
the next safe action.

Forbidden claim: a shared live prerequisite gives the controller actor-facing Play
authority.

## Raw Diagnostic

```text
qualified operator
  -> explicit diagnostic projection
  -> app-owned raw-exec adapter
  -> ready Tuner resource
  -> exact raw response and audit evidence
```

This path is not imported by Controller, Play, MapGen-runs, or ordinary product
commands. Window capture is likewise separate generic diagnostic/app evidence.

## CLI Projection

```text
terminal actor
  -> commandless CLI app and native topic discovery
  -> one topic projection
  -> app-bound public client or qualified capability
  -> owner result
  -> structured terminal presentation
```

Forbidden claim: a command owns provider lifecycle, service policy, or a
parallel contract.

## Proof Composition

```text
owner fact
  -> exact input/revision/epoch/environment
  -> named proof class
  -> caller projection
  -> actor Question and next lawful action
```

Generated, installed, loader, and live-behavior facts may all exist, conflict,
or be absent independently. No projection chooses a strongest status.
