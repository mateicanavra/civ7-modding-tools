## Authority Lanes

1. **Current instruction and scope:** explicit user direction and applicable
   repo/subtree `AGENTS.md` files control the task and workflow.
2. **Civ7 product and destination meaning:** the sealed packet above controls
   owner selection. Stale routers or canonical descriptions do not override an
   accepted project model.
3. **Shared structural law:** the installed release's published upstream
   Habitat packets own the selected shared kind shells and structure/source
   relations. Civ7 may select them and add accepted qualified product facts;
   it may not fork or locally reproduce them. Local Civ7 service law remains
   the service authority unless the sealed model selects an upstream successor.
4. **Generic vendor mechanics:** use global `dev:effect-orpc`, `dev:effect-ts`,
   and `dev:orpc` guidance. For syntax, lifecycle, or API behavior that varies
   by version, exact installed package source and fixtures outrank a profile
   verified against a different version.
5. **Promoted canonical guidance:** evergreen product/system/process docs and
   ADRs apply where they agree with, or explicitly incorporate, the sealed
   model.
6. **Implementation evidence:** current source, tests, dependency graphs, and
   generated artifacts describe behavior and migration scope, not destination
   authority.
7. **External evidence:** official Civ7 resources and live checks support only
   the exact game fact or runtime observation inspected.

## Re-Grounding Procedure

1. Read the relevant sealed capability, placement, outcome, and topology rows.
2. Name the actor Task or Question and each owner-local fact.
3. Classify current paths as keep, move, consolidate, or delete evidence.
4. Resolve generic structure upstream and generic framework mechanics globally.
5. Check the exact construction/admission state in the sealed project sources;
   do not copy it into this overlay.
6. If evidence falsifies the model, reopen the owning sealed authority before
   implementing an alternate topology.

## Excluded Inputs

Do not derive target architecture from:

- legacy package families, facade method inventories, or compatibility
  wrappers;
- archived docs, chat carry-forward, scratch summaries, or generated trees;
- dormant/unselected Habitat SDK material or a Civ7-local generic blueprint;
- framework examples for a different installed version;
- tests that pass only through the owner being deleted.
