# Failure Patterns

Open this reference when current topology or framework mechanics start deciding
the design.

| Failure | Symptom | Repair |
| --- | --- | --- |
| Current path becomes authority | A mixed package or source folder survives because it already works | Return to the sealed capability and topology models; classify the path as migration evidence |
| Package becomes an integration cabinet | Pure code acquires sockets, reads files, imports engine globals, starts a process, or owns product state | Move acquisition/effects to providers or qualified app adapters and semantics to the service/definition owner |
| Resource/provider collapse | The resource selects a concrete transport or the provider defines Civ7/play policy | Keep provider-neutral vocabulary in the resource, concrete acquisition in the provider, and selection in the app |
| Controller/Play collapse | Native execution and actor-facing strategy collapse into one owner because both need live readiness | Keep typed native operations in the realm-local controller and gameplay meaning in Play over the public controller client |
| Host binding becomes implementation | A Tuner transport resends mature JavaScript bodies or becomes a second operation contract | Bind the controller-owned public client to the versioned ingress with envelopes only; keep caller-authored JavaScript diagnostic |
| Window evidence becomes controller input | Capture acquisition or image interpretation is required to construct or call the controller | Keep capture as generic diagnostic or qualified app evidence, independent of Controller and Play |
| Facade survival | A wrapper preserves the former mixed method inventory or extracts types from another surface | Delete it; bind and call the independent public clients |
| Projection becomes service | API/CLI code owns run state, gameplay policy, provider construction, or private service types | Project public owner clients and keep caller policy only |
| App becomes semantic owner | Composition code duplicates contracts or decides capability outcomes | Limit the app to selection, acquisition, binding, mounting, qualified effects, observation, and disposal |
| Swooper realization collapse | Studio invokes production realization targets or the production app becomes a reusable runtime | Keep production build/deploy in the realization app and Studio's ephemeral effects in its own adapter |
| MapGen-runs effect collapse | The service writes source/files or the adapter decides the operation result | Keep transaction meaning in MapGen-runs and physical effects/receipts in app adapters |
| Direct-control replacement | A renamed convenience surface recreates raw transport plus semantic methods | Delete the shape; expose only explicit resource diagnostics or the exact controller/Play client |
| Local platform fork | Civ7 authors generic kind constructors or copies shared blueprints | Use upstream Habitat and keep only accepted qualified Civ7 overlays |
| Vendor-guide fork | Local docs reproduce generic Effect/oRPC recipes or assume another version's behavior | Route to global vendor skills and prove version-sensitive claims against exact installed source |
| Workflow by analogy | Process-local run state becomes a workflow because it has several steps | Keep it service-owned until process-independent resume/retry/replay is an actual requirement |
| Proof inflation | Build, generated output, installation, or readback is called end-to-end success | Report independent evidence classes and the still-missing facts |

## Smell Tests

- Would this owner still exist if the current path vanished?
- Which actor outcome and owner-local fact justify the container?
- Is this edge authority, construction, projection, or proof?
- Does a shared prerequisite masquerade as shared semantic ownership?
- Does Studio's ephemeral realization import or depend on the production app?
- Is the adapter returning an exact receipt or deciding another owner's result?
- Is a local rule adding qualified Civ7 fact or recreating generic platform law?
- Which proof classes were actually exercised, and which remain absent?
